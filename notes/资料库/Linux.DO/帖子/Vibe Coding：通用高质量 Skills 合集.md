我把个人的 Skills 开源了：[GitHub - xstongxue/best-skills: 通用高质量 Agent Skills 合集](https://github.com/xstongxue/best-skills)

这套 best-skills 是我在写学位论文、做自媒体、写代码时一点点攒出来的。覆盖论文全流程（大纲审核、结构仿写、润色去AI化、参考文献、答辩PPT、架构图）、开发四步法（需求→设计→实现→审查）、公众号撰写与配图、周报汇报总结、项目梳理和简历描述等。

与之前开源的 [Vibe Coding：通用高质量 Prompt 合集- 开发调优 - LINUX DO](https://linux.do/t/topic/1666272)不同，Skills 装一次就永久生效——Cursor、Claude Code、Trae 等 Agent 工具会根据你说的话自动匹配并调用，不用每次手动找 Prompt。

支持 Cursor、Claude Code、Codex、Trae、OpenClaw 等主流工具，复制对应文件夹到 skills 目录即可使用。项目会持续扩展，欢迎 Star、Fork、提 Issue 和 PR。
