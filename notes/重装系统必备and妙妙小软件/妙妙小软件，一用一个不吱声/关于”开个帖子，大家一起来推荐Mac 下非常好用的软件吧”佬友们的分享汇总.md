Mac 软件/网站推荐汇总（去重）

一、应用 / 软件（去重汇总）
> 1. 启动器 / 效率


• **Alfred**：启动器 / 自动化工作流

• **Raycast**：启动器 + 插件生态（很多功能一体化）

• **uTools**：效率工具平台（插件化）

• **Setapp**：订阅制软件集合
> 1. 剪贴板 / 截图 / 录屏


• **Paste / PasteNow / Pastebot**：剪贴板历史管理

• **Maccy**：开源剪贴板管理

• **CleanClip**：剪贴板（支持队列粘贴）

• **CleanShot X**：截图 / 标注

• **Shottr**：截图工具

• **iShot**：截图工具

• **Kap**：录屏 / GIF（开源）

• **QuickTime**：系统自带录屏 / 播放器

• **QuickRecorder**：录屏工具

• **Screen Studio**：录屏 / 演示类
> 1. 翻译 / OCR / 辅助


• **Bob**：OCR + 翻译（原贴提到旧版 v0.10）

• **pot（pot-desktop）**：翻译工具（开源）

• **Easydict**：开源词典 / 翻译

• **PixPin**：截图 / OCR（原贴出现官方日志链接）
> 1. 终端 / SSH / 开发


• **iTerm2**：终端

• **Warp**：新终端

• **wezterm**：终端

• **Ghostty**：终端（有人提到 iTerm2 替代、占用低）

• **Tabby**：终端 / SSH（开源）

• **Termius**：SSH 客户端

• **Homebrew**：包管理器

• **Docker**：容器

• **Colima**：Docker 替代/后端

• **OrbStack**：容器 / 虚拟化

• **Whisky**：Wine / Windows 应用运行

• **youtube-dl**：视频下载工具
> 1. 窗口管理 / 键鼠增强 / 菜单栏


• **Magnet**：窗口分屏

• **Loop**：窗口管理（开源）

• **AeroSpace**：平铺窗口管理

• **AutoFocus**：自动聚焦窗口（开源）

• **AltTab / Alt-Tab**：应用切换增强

• **Karabiner-Elements**：键盘改键

• **Mos**：鼠标滚轮/平滑增强（开源）

• **Mac Mouse Fix**：鼠标增强（开源）

• **Ice**：菜单栏管理（开源）

• **Hidden Bar**：菜单栏图标隐藏

• **TomatoBar**：番茄钟（开源）

• **Scroll Reverser**：滚动方向控制

• **Keyboard Maestro**：自动化/宏

• **keyboardholder**：键盘相关小工具

• **Kando**：圆盘菜单

• **Middle**：触控板模拟中键/滚轮
> 1. 网络 / 抓包 / 安全


• **Surge**：网络代理/规则

• **Proxyman**：抓包代理

• **Little Snitch**：出站防火墙/联网控制

• **Microsoft Defender / Windows Defender**：安全防护

• macOS 自带防火墙：系统内置

• [Motrix: 开源下载工具 - 最近一次更新是3年前](https://github.com/agalwood/Motrix)
> 1. 远程 / 虚拟机


• RustDesk：远程控制

• Parallels Desktop：虚拟机

• UTM：虚拟机（开源）

• Windows App（原 Microsoft Remote Desktop）：远程桌面

• Devolutions Remote Desktop Manager：远程连接管理
> 1. 影音 / 文件 / 清理


• IINA：视频播放器

• Infuse：媒体库播放器

• Transmit：SFTP / 文件传输（Panic 出品）

• Free Download Manager / Neat Download Manager：下载管理器

• Pearcleaner：轻量卸载/清理（开源）

• CleanMyMac X：系统清理工具

• Sloth：进程/资源占用查看

• Macs Fan Control：风扇控制

• OmniDiskSweeper：磁盘空间扫描

• WinRAR / Bandizip / Keka：压缩工具

• X Lossless Decoder：音频转码

• XnView MP：看图/图片管理

• Linearity Curve：矢量/设计

• Notion：笔记

• MWeb：写作 / Markdown

• [Mole](https://github.com/tw93/Mole): 开源清理软件
> 1. 美化


• pap.er: 高清桌面壁纸（App Store可免费下载使用, 没再更新了但是图库一直能刷到新的）
