## 4.4 安装xrayr内核

1. 这个是你这个机子建立节点的关键，在ssh上运行`wget -N https://raw.githubusercontent.com/XrayR-project/XrayR-release/master/install.sh && bash install.sh`，等待安装完成。![image.png|450](https://cdn3.ldstatic.com/original/4X/4/a/b/4ab2a0ebc26ff16969ac8fd91a8ccff547bec208.png)
2. 有人要问了，为啥不用其他多合一脚本，因为我只会Xrayr和Xboard的搭建，其他的不会。（如果不想和xboard通讯，后边会给多合一脚本直接提取节点链接）
3. 这个界面先放在这不管。

## 4.6 Xrayr内核与Xboard的通信

1. 接下来是重头戏了，能不能成功就看这个了。
2. 进入你的Xboard后台，记住是管理员后台，而不是机场用户面板![image.png|450](https://cdn3.ldstatic.com/original/4X/7/b/8/7b8f1ba04513c7833b3bb12d07fa2c9cbc2cfb49.png)
3. 点击添加节点，选择Vless，你问我为什么选这个，因为我只会这个（这个比较稳，不容易封，但是比较吃配置，此配置非vps配置，而是节点设置，不过个人用有模版，配置好一次接下来可以套娃）![image.png|450](https://cdn3.ldstatic.com/original/4X/4/2/9/429bc1c96efd8a9fe843c13cb985ccfc2fcd72bf.png)
4. 伪装站点：`mensura.cdn-apple.com`，我没记错的话应该是Apple的测速地址。（这个可以AI一下，我怕我解释不清楚你们骂薯薯）![image.png|450](https://cdn3.ldstatic.com/original/4X/1/3/9/1398323f70ba308e5c8cee9406b76b720eb49e59.png)![image.png|450](https://cdn3.ldstatic.com/original/4X/f/7/f/f7fa3d0e7c91fb9e7c21c8a0498aeeccce42859d.png)

6. 接下来ssh链接xrayr的vps，然后SFTP去编辑xrayr的配置文件![image.png|450](https://cdn3.ldstatic.com/original/4X/b/9/7/b97baea30750a85f09f71d98841267596bb52e90.png)

## 4.7 加速小技巧

1. 我之前买了一个SG新加坡的，安装上述流程配置好后，发现1G的网只有几十Mbps，给我难受的，但是喵佬给我了一个加速脚本，运行完后达到了500Mbps，我觉得很玄学，大家如果有相同问题可以试试。

```
bbr安装&设置（推荐使用原版bbr+FQ加速）：
wget http://sh.xdmb.xyz/tcp.sh && bash tcp.sh
tcp窗口调优（先启用bbr，再调优）：
wget sh.xdmb.xyz/d11.sh && bash d11.sh
检测bbr启动成功与否：
lsmod | grep bbr
输入上行命令，如果有输出信息则表示启动成功‌
属于第一行后选11
然后依次输入2,3行
```

# 6 多合一脚本直接提取节点连接

1. 我用的脚本是：`bash <(wget -qO- -o- https://github.com/233boy/sing-box/raw/main/install.sh)`，只需要在ssh执行这行命令，这样就算安装好勒，那个vless链接其实就是一个节点连接。![image.png|450](https://cdn3.ldstatic.com/original/4X/9/5/2/952478eb72232478adf4e1f08d4b8cef15805673.png)
2. 找一个订阅转换工具，把这个链接转换成你能直接导入clash的形式，这里我用的喵佬的（我没记错的话） [订阅转换](https://linuxdo.icmpmiao.cc/)
3. 转换后，就可以复制链接导入到clash中试试![image.png|450](https://cdn3.ldstatic.com/original/4X/5/f/a/5fad65320ef50fc93246f109a596da86e68b0f60.png)
4. 但是我广东这很容易timeout，所以我就没有用这种方式![image.png|450](https://cdn3.ldstatic.com/original/4X/4/7/f/47fc52c5cf510ebfd01dde9d965b64216a869497.png)
5. 当然也可以换成其他协议，在ssh上输入`sb`，你会看到这个界面，然后点击添加配置就可以了，剩下的就不演示了（因为我不咋用）。![image.png|450](https://cdn3.ldstatic.com/original/4X/9/4/8/948cb493d84db20e7c5dc8a822b001b6087f57b8.png)
