## 数据

Hugging Face `yiming421/ucbshift-refined`，revision `5607172912efa5fdc57c9c0fbe449c0ce45572cc`。
使用数据集自带划分：**train 678 / validation 75 / test 200** 个蛋白，测试集共 79,071 个可评估位点。
两个重训模型用完全相同的 train/validation，SHIFTX2 只在同一 test 上推理。

## 三个基线

| 基线 | 是否用本数据集 train/validation 重训 |
|---|---|
| **NMR-GNN** | ✅ 是，官方发布模型从头重训 |
| **LEGOLAS** | ✅ 是，官方发布架构按其论文配方从头重训 |
| **SHIFTX2** | ❌ 否，官方包只发布训练好的模型、不提供训练器，只能原样运行 |

## 说明

**统计判定**基于蛋白层面 bootstrap 重采样（10,000 次）。
标 ⚠ 的项虽然 RMSE 上分出高低，但逐蛋白比较没有一致优势，差异由少数蛋白的大误差驱动，不宜说成"整体更优"。

**SHIFTX2 的 hybrid 模式未列入**：其 51% 的 HA 位点误差小于 0.01 ppm，属于从参考库中检索到测试蛋白本身，不是预测。

**这个划分不是同源受控的**：200 个测试蛋白里有 109 个与 train/validation 中的蛋白落在同一同源簇（MMseqs2，序列一致性 ≥0.30、覆盖度 ≥0.80、E ≤1e-3）。这是数据集自带划分本身的性质，对两个重训模型的影响相同，但意味着上面的数字包含同源泄漏，不能当作对全新序列的泛化能力。

**SHIFTX2 不是同等条件**：它未在本数据集重训（官方不提供训练器），是在其他数据上训练好的成品模型；且其自身 2011 年训练集与本测试集有 61/200 的同源重叠。因此它与两个重训模型不构成公平比较，列出仅作参考。


## 结论

- LEGOLAS 在 CA、H、HA 上更低；NMR-GNN 在 C、N 上更低（但这两项及 CB 缺乏逐蛋白一致性）。
- SHIFTX2 虽未重训，多数原子与两个重训模型同量级，HA 最低、N 最高。
