# PLASMA 7-Backbone 实验复现总结

## 表头说明

| 列名          | 含义                                      |
| ----------- | --------------------------------------- |
| Backbone    | 用的哪个蛋白质语言模型                             |
| Test ROCAUC | 复现结果，在 test_frequent（训练时见过的家族）上的 ROCAUC |
| 论文 inter    | 论文报告的 test_inter（同一个测试集）的 ROCAUC        |
| Hard ROCAUC | 复现结果，在 test_hard（训练时没见过的家族）上的 ROCAUC    |
| 论文 extra    | 论文报告的 test_extra（同一个测试集）的 ROCAUC        |
| Test F1     | 复现结果，在 test_frequent 上的 F1-max          |
| 论文 F1       | 论文报告的 test_inter 上的 F1-max              |
|             |                                         |
|             |                                         |

对应关系：
- 复现的 test_frequent = 论文的 test_inter（训练时见过的家族）
- 复现的 test_hard = 论文的 test_extra（训练时没见过的家族）

均值列的数据由逐 Split 详细结果的 3 折平均计算得出。

## 与论文对比总结

### 一致的部分
- **binding_site 和 active_site 高度吻合**：所有 backbone 与论文差距 < 0.01
- **Backbone 排名基本一致**：ProstT5 ≈ ProtT5 ≈ Ankh > ESM2 ≈ ProtSSN > TM-Vec > ProtBERT

### 有差异的部分
- **motif + ESM2**：test ROCAUC 0.918 vs 论文 0.96（差 -0.042），最大偏差
- **motif + ProtSSN**：test ROCAUC 0.920 vs 论文 0.96（差 -0.040）
- **motif + ProtBERT**：test ROCAUC 0.841 vs 论文 0.87（差 -0.029）
- **hard 测试集普遍偏高**：可能因为 test_extra 与 test_hard 划分逻辑不完全相同
- **binding_site + ProtBERT split1**：Hard ROCAUC 0.8559 为异常值
